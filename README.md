# Animo Label Website
Website company profile + katalog produk Animo Label. PHP 8 + MySQL, tanpa keranjang/checkout.

## Fitur
- Homepage modern, responsive
- Katalog produk dengan harga & keterangan opsional
- Kategori, banner, portfolio, layanan, tentang, kontak
- WhatsApp CTA
- Admin CMS untuk mengelola konten dan upload gambar
- Siap dipindahkan ke cPanel

## Development
GitHub dipakai sebagai source code. PHP/MySQL perlu dijalankan di XAMPP/Laragon atau hosting/staging; GitHub Pages tidak menjalankan PHP.

## cPanel
Import database/animo_label.sql, lalu isi config/database.php sesuai database cPanel.
